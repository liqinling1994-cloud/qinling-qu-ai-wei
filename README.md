## 🚀 快速开始

### 安装方法

#### 方法1：手动安装（推荐）

1. 解压本压缩包
2. 将整个 `去AI味引擎` 文件夹复制到你的 Claude Code skills 目录：
   ```
   Windows: C:\Users\[你的用户名]\.claude\skills\
   Mac/Linux: ~/.claude/skills/
   ```
3. 重启 Claude Code 或运行 `/refresh` 命令

#### 方法2：Git 克隆（适合开发者）

```bash
cd ~/.claude/skills/
git clone [仓库地址] 去AI味引擎
```

### 验证安装

在 Claude Code 中输入以下命令验证安装：

```
/去AI味引擎
```

或者说：

```
帮我去AI味
```

如果 skill 正常响应，说明安装成功！

## 📖 使用指南

### 三种使用方式

#### 1. 场景直达（最简单）

直接说明你的场景，AI 自动匹配：

```
用公众号模板写一篇关于职场的文章
```

#### 2. 技法指定（进阶）

指定技法组合：

```
用白描+杂文的技法写一段...
```

#### 3. 智能推荐（推荐）

描述任务，让 AI 推荐最佳方案：

```
我要写一篇小红书种草笔记，推荐用什么技法？
```

### 完整工作流程

```
场景识别 → 技法推荐 → 模板应用 → 效果验证 → 优化建议
```

详细使用方法请参考：[去AI味引擎V2.0-功能使用指南.md](./去AI味引擎V2.0-功能使用指南.md)

## 📊 效果评估

### S/A/B/C 等级制

- **S级**：通过10-12项检验，极强去AI味
- **A级**：通过7-9项检验，明显去AI味
- **B级**：通过4-6项检验，基础去AI味
- **C级**：通过0-3项检验，效果不明显

### 12项检验标准

**结构层面（3项）**
1. 避免"总-分-总"三段论
2. 避免对称式小标题
3. 段落长短参差不齐

**语言层面（4项）**
4. 减少形容词堆砌
5. 避免逻辑连接词过多
6. 避免套话
7. 有口语化表达

**思维层面（3项）**
8. 有明确的个人立场
9. 有具体细节
10. 有"不完美"感

**情感层面（2项）**
11. 有真实情绪
12. 读完感觉"像人写的"

## 💡 技法速查

### 6大类，21种核心技法

1. **技法类**（6种）：白描、速写、素描、特写、写生、勾勒
2. **文体类**（7种）：杂文、随笔、笔记、札记、书信体、日记体、流水账
3. **风格类**（7种）：冷峻、峭拔、疏淡、简洁、克制、冷静、疏离
4. **作家标签**：鲁迅式、王小波式、沈从文式...
5. **跨文化技法**（3种）：弹幕式、第二人称、意识流

### 高协同组合（效果最佳）

| 组合 | 适合场景 | 效果 |
|------|---------|------|
| 杂文 + 书信体 | 公众号观点 | 有态度又亲近 |
| 速写 + 流水账 + 第二人称 | 小红书种草 | 真实代入感强 |
| 白描 + 特写 + 冷峻 | 深度报道 | 专业级效果 |
| 意识流 + 第二人称 | 情感文章 | 情绪感染力强 |

## 🔧 常见问题

### Q1：如何选择合适的模板？

**A**：三种方式
1. 直接说场景："用公众号模板"
2. 让AI推荐：描述需求，AI自动推荐
3. 查表选择：参考场景推荐表

### Q2：可以自己组合技法吗？

**A**：可以！说"用白描+杂文"即可。建议参考高协同组合列表，避免负向组合。

### Q3：效果不理想怎么办？

**A**：
1. 查看效果验证的等级评估
2. 根据优化建议调整
3. 或尝试其他技法组合

### Q4：与其他写作 skill 的关系？

**A**：
- 本 skill 专注于"去AI味"优化
- 可与智能创作、素材提取等 skill 配合使用
- 支持独立使用，也支持作为写作流程的最后一环
