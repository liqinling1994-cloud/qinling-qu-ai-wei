```bash
npx skills add liqinling1994-cloud/qinling-qu-ai-wei
```

安装以后，把原稿、写作场景和希望保留的语气交给 Agent：

```text
用中文去AI味skill重写下面这段公众号稿。
保留事实和观点，减少套话与整齐句式，增加具体细节和自然停顿。
```

它会按这条链路处理：**场景识别 → 技法推荐 → 模板应用 → 效果验证 → 优化建议**。

**V2.1.0 内容基线：** 21 种核心技法、15 个实战模板、20+ 场景映射、12 项自然度检验、3 个完整改写案例。

## 为什么做这个 Skill

很多 AI 中文稿一眼就能看出共同痕迹：

- 开头先交代背景，结尾统一升华，结构过分规整。
- “首先、其次、此外、综上所述”密集出现，句子被逻辑词牵着走。
- 形容词、排比句和正确结论很多，人物、动作、现场和真实感受很少。
- 各段长度接近，语气始终平稳，缺少停顿、跳跃和个人脾气。
- 改写工具常常只做同义替换，信息没变，模板感仍然存在。

中文去AI味skill把这些问题拆成可执行的写作技法。它会根据场景选用白描、杂文、书信体、速写、流水账、第二人称等组合，并在改写后逐项复检。

## 它能处理哪些任务

### 直接改写

提供原稿后，Skill 会识别场景与主要问题，选择合适技法并输出改写稿。适合公众号文章、社交媒体内容、个人表达、书评影评、旅行游记和产品体验等内容。

### 从零起草

提供主题、平台、读者、事实素材和语气要求后，Skill 会调用对应模板起草。涉及个人经历、产品体验或案例数据时，只使用用户已经提供的事实。

### 诊断与复检

用户可以只要诊断，不改原文。Skill 会依据 12 项检验规则定位模板化结构、逻辑词滥用、空泛表达、细节不足和情绪失真等问题。

### 技法学习与组合

用户可以查询单一技法，也可以指定组合。知识库记录了高协同组合、普通组合和应避免的冲突组合。

## 一套完整工作流

1. **场景识别**：确认内容类型、发布平台、目标读者、篇幅和语气。
2. **边界确认**：锁定必须保留的事实、观点、术语、引语和结构要求。
3. **技法推荐**：选择 1–2 个主力技法，必要时增加 1 个辅助技法，并说明理由。
4. **模板应用**：匹配 Level 1、Level 2 或 Level 3 模板，完成生成或改写。
5. **效果验证**：按结构、语言、思维、情感四个维度检查 12 项指标。
6. **优化建议**：根据 S / A / B / C 等级指出仍需调整的具体位置。

## 技法与模板体系

### 21 种核心技法

| 类型 | 代表技法 | 主要作用 |
|---|---|---|
| 描写技法 | 白描、速写、素描、特写、写生、勾勒 | 增加现场、动作和可感知细节 |
| 文体技法 | 杂文、随笔、笔记、札记、书信体、日记体、流水账 | 改变叙述姿态与段落组织 |
| 语气风格 | 冷峻、峭拔、疏淡、简洁、克制、冷静、疏离 | 控制语言温度、力度与距离 |
| 跨文化技法 | 弹幕式、第二人称、意识流 | 增强互动、代入和心理流动 |

完整定义与组合规则见 [`references/keyword-database.md`](references/keyword-database.md)。

### 15 个实战模板

| 等级 | 数量 | 用途 | 代表模板 |
|---|---:|---|---|
| Level 1 | 6 | 单一技法快速上手 | 白描叙事、杂文批评、书信倾诉 |
| Level 2 | 6 | 双技法或三技法组合 | 杂文书信、白描纪实、意识流第二人称 |
| Level 3 | 3 | 平台与任务深度定制 | 公众号价值观、小红书种草、深度调查报道 |

模板目录见 [`references/templates/`](references/templates/)，场景匹配见 [`references/scene-mapping.md`](references/scene-mapping.md)。

## 它会输出什么

根据请求，输出可以包含以下部分：

```text
场景识别结果
推荐技法与选择理由
改写稿或完整提示词
12 项效果验证
S / A / B / C 等级
针对未通过项的修改建议
```

用户要求直接交付成稿时，Skill 会压缩过程说明，把成稿放在前面。

## 常见问题

| 问题 | 处理方式 |
|---|---|
| Skill 没有被识别 | 确认目录名为 `qinling-qu-ai-wei`，并检查根目录存在 `SKILL.md` |
| 改稿丢失原意 | 明确列出必须保留的事实、观点、术语和引语，再重新执行 |
| 文字更口语但仍然空 | 补充人物、动作、时间、地点、感官或真实经历，禁止模型自行编造 |
| 风格太用力、影响阅读 | 将技法强度调为“轻度”或“标准”，减少同时启用的技法数量 |
| 不想重写全文 | 说“只诊断”或“只改第 3—5 段” |
| 检测工具仍判为 AI | 本 Skill 优化中文表达质量，不承诺绕过任何检测器 |

## 使用边界

- 优先保留用户提供的事实、立场、专业术语、数据和引语。
- 不补写未经用户提供的个人经历、产品体验、采访细节或统计数据。
- 学术论文、法律文书、正式报告和技术文档更看重规范与精确，默认不启用强烈的口语化与跳跃表达。
- 作家标签用于分析抽象技法，避免复刻在世作者的独特文风。
- S / A / B / C 是基于规则的质量分级，不代表人工盲评或 AI 检测结论。

## English

`qinling-qu-ai-wei` is a Chinese writing refinement skill that reduces formulaic structure, stock transitions, empty abstraction, and overly even rhythm while preserving the user's facts and point of view.

It includes 21 writing techniques, 15 reusable templates, scenario-aware technique selection, a five-stage workflow, and a 12-item review rubric.

```bash
npx skills add liqinling1994-cloud/qinling-qu-ai-wei
```

Try saying:

- “Rewrite this Chinese article with a more natural rhythm while preserving every fact.”
- “Diagnose the AI-like patterns first, then revise only the affected paragraphs.”
- “Use the WeChat article template and keep the author's critical stance.”
