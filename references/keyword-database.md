# 关键词知识库

本文档详细记录了21种核心技法的定义、使用要点、适用场景和组合策略。

---

## 一、技法类（6种）

### 【技法1：白描】

**定义**：
用最简洁的文字勾勒事物轮廓，不加修饰和渲染，如同中国画中的白描技法。

**核心特征**：
- 删除80%以上的形容词和副词
- 只用名词+动词，直接呈现事实
- 避免任何主观评价和情绪渲染
- 像速写本一样记录，不加工

**约束机制**：
```
✓ 允许：他走进房间，坐下，点了根烟
✗ 禁止：他疲惫地走进昏暗的房间，缓缓坐下，若有所思地点了根烟
```

**适用场景**：
- 纪实类写作（新闻、调查报道）
- 需要客观冷静的叙述
- 人物动作和场景描写
- 对话记录

**不适用场景**：
- 需要情感渲染的抒情文
- 营销文案（需要煽动性）
- 散文诗（需要意境）

**使用强度建议**：标准（删除大部分形容词，保留基本描述词）

**提示词要素**：
```
- 删除所有形容词和副词
- 只用"名词+动词"结构
- 不要评价，只描述看到的
- 像摄像机一样记录，不加工
```

---

### 【技法2：速写】

**定义**：
快速捕捉印象和瞬间，像素描本上的速写，保留粗糙感和即时性。

**核心特征**：
- 允许不完整的句子和跳跃
- 捕捉第一印象，不修改润色
- 保留口语化和随意性
- 像现场笔记，不求精确

**约束机制**：
```
✓ 允许：下雨了。伞。忘带了。湿透。
✗ 禁止：天空突然下起了雨，我这才想起忘记带伞，瞬间被淋得湿透。
```

**适用场景**：
- 现场记录类文章
- 旅行见闻
- 快速印象记
- 小红书种草笔记

**不适用场景**：
- 正式报告
- 逻辑严密的论述文
- 需要完整叙述的故事

**使用强度建议**：标准（保持句子完整度40-60%）

**提示词要素**：
```
- 允许不完整的句子
- 用短句，断句，省略号
- 捕捉第一印象，不要二次加工
- 像速写本，保留粗糙感
```

---

### 【技法3：素描】

**定义**：
比速写更完整，但保留结构感和层次感，像素描画注重明暗关系。

**核心特征**：
- 有完整的结构，但不追求精致
- 突出重点细节，其他部分简略
- 保留思考过程和层次感
- 像草稿，但能看清全貌

**约束机制**：
```
✓ 允许：他的脸上有三处明显变化：眼神、嘴角、额头的皱纹。眼神最重要。
✗ 禁止：他的脸上展现出复杂而微妙的表情变化...（铺陈过多）
```

**适用场景**：
- 人物特写
- 场景描写（突出重点）
- 分析类文章的框架搭建

**不适用场景**：
- 需要精雕细琢的文学作品
- 简短快速的记录

**使用强度建议**：标准（结构完整度60-80%）

---

### 【技法4：特写】

**定义**：
聚焦某个细节，放大呈现，像电影中的特写镜头。

**核心特征**：
- 只写一个细节，其他全部虚化
- 用具体的感官描写（视觉、听觉、触觉）
- 避免宏大叙事，只盯住一个点
- 让读者看到放大的瞬间

**约束机制**：
```
✓ 允许：他的手指在键盘上停了三秒。第一秒，悬着。第二秒，抖了一下。第三秒，按下。
✗ 禁止：他思考良久后终于做出了决定...（太概括）
```

**适用场景**：
- 关键时刻的呈现
- 情绪转折点
- 细节描写

**不适用场景**：
- 需要宏观视角的文章
- 快节奏叙述

**使用强度建议**：强化（极致聚焦一个点）

---

### 【技法5：写生】

**定义**：
像画家对着实物写生，忠实还原眼前所见，不添加想象。

**核心特征**：
- 完全基于观察，不加想象
- 细节真实，但不追求文学性
- 像现场报道，强调在场感
- 用第一视角"我看到"

**约束机制**：
```
✓ 允许：我看到他穿着黑色夹克，左手拿着咖啡杯，右手在翻手机。
✗ 禁止：他似乎在等什么人...（加入了推测）
```

**适用场景**：
- 现场报道
- 纪录片式写作
- 需要强调真实性的文章

**使用强度建议**：标准

---

### 【技法6：勾勒】

**定义**：
用寥寥几笔勾出轮廓，点到为止，留白多于实写。

**核心特征**：
- 高度概括，不展开细节
- 用关键词串联，省略过渡
- 像电报文体，惜字如金
- 让读者自己补全

**约束机制**：
```
✓ 允许：见面。握手。沉默。离开。
✗ 禁止：他们见面后握了握手，陷入了短暂的沉默，随后各自离开。
```

**适用场景**：
- 极简风格文章
- 需要快速推进的叙事
- 营造距离感

**使用强度建议**：强化（极致精简）

---

## 二、文体类（7种）

### 【文体1：杂文】

**定义**：
有明确立场和态度的议论文体，允许情绪化和跳跃性思维。

**核心特征**：
- 必须有明确的立场，不打太极
- 允许直接表达情绪（愤怒、讽刺、焦虑）
- 不追求逻辑严密，可以跳跃
- 允许使用反问、讽刺、夸张

**约束机制**：
```
✓ 允许：说实话，我真的受够了这种"为你好"的说辞。
✗ 禁止：从某种角度来看，这种说法可能存在一定的问题...(太客观)
```

**适用场景**：
- 观点评论
- 批判性文章
- 公众号价值观输出
- 时事评论

**不适用场景**：
- 学术论文
- 正式报告
- 需要中立的新闻报道

**使用强度建议**：标准（有态度但不极端）

**提示词要素**：
```
- 必须有明确的立场和态度
- 允许直接表达情绪
- 不要追求"客观中立"
- 可以打破逻辑严密性
- 允许跳跃性思维
```

---

### 【文体2：随笔】

**定义**：
随意而写，不拘形式，像和朋友聊天一样的文体。

**核心特征**：
- 结构松散，想到哪写到哪
- 允许离题，允许闲笔
- 像絮叨，不求简洁
- 保留思考过程的曲折

**约束机制**：
```
✓ 允许：说到这个，我突然想起另一件事...
✗ 禁止：（严格按照提纲，一二三条列清楚）
```

**适用场景**：
- 个人博客
- 生活感悟
- 读书笔记
- 随想录

**使用强度建议**：标准

---

### 【文体3：笔记】

**定义**：
像读书笔记或工作笔记，只记要点，不追求完整。

**核心特征**：
- 用要点式、条目式
- 可以有符号（✓、→、·）
- 省略主语和连接词
- 像备忘录，给自己看

**约束机制**：
```
✓ 允许：
  - 要点1：XXX
  - 要点2：XXX
  → 结论：XXX

✗ 禁止：首先，我们来看第一点...然后...最后...
```

**适用场景**：
- 知识总结
- 会议记录
- 快速梳理

**使用强度建议**：标准

---

### 【文体4：札记】

**定义**：
类似笔记，但更文学化，有思考深度，像明清文人的读书札记。

**核心特征**：
- 保留笔记的简洁
- 但有更多思考和延伸
- 用短段落，每段一个想法
- 像思维碎片的记录

**适用场景**：
- 深度思考类文章
- 哲学随想
- 文学评论

**使用强度建议**：标准

---

### 【文体5：书信体】

**定义**：
像写信一样，用"你"来称呼读者，营造对话感。

**核心特征**：
- 全文用第二人称"你"
- 可以直接对话："你有没有发现..."
- 允许省略主语，口语化
- 可以用"对吗？""是吧？"等反问

**约束机制**：
```
✓ 允许：你有没有遇到过这种情况？对吧？
✗ 禁止：读者可能会遇到这种情况。（太客观）
```

**适用场景**：
- 公众号情感类文章
- 需要亲近感的内容
- 倾诉型文章

**不适用场景**：
- 正式报告
- 学术文章

**使用强度建议**：完整使用（全篇第二人称）

**提示词要素**：
```
- 全文用第二人称"你"来写
- 像写给朋友的信
- 允许省略主语，口语化
- 可以用反问："对吗？""是吧？"
- 整体语气是倾诉和交流
```

---

### 【文体6：日记体】

**定义**：
像日记一样，用第一人称"我"，记录个人经历和感受。

**核心特征**：
- 用第一人称"我"
- 按时间线叙述
- 包含个人感受和情绪
- 像私密记录，不顾及读者

**适用场景**：
- 个人成长类文章
- 经历分享
- 自传体写作

**使用强度建议**：标准

---

### 【文体7：流水账】

**定义**：
按时间顺序记录，不加提炼和总结，像记账一样平铺直叙。

**核心特征**：
- 严格按时间线
- 不做归纳总结
- 平铺直叙，不分主次
- 像记账本，事无巨细

**约束机制**：
```
✓ 允许：早上8点起床。8点半吃早饭。9点出门。
✗ 禁止：早上的行程安排如下...（有归纳）
```

**适用场景**：
- 小红书种草（使用流程记录）
- 旅行日记
- 需要真实感的体验分享

**不适用场景**：
- 需要提炼观点的文章
- 深度分析

**使用强度建议**：标准

**提示词要素**：
```
- 按时间顺序记录
- 不做提炼和总结
- 平铺直叙，事无巨细
- 像记账本一样
```

## 三、风格类（7种）

### 【风格1：冷峻】

**定义**：
冷静、克制、不动声色的叙述风格，像冷眼旁观者。

**核心特征**：
- 删除所有情绪词汇
- 用短句，断句
- 避免抒情和煽动
- 保持距离感

**约束机制**：
```
✓ 允许：他死了。就这样。没有葬礼。
✗ 禁止：他悲惨地离开了人世，令人唏嘘不已。
```

**适用场景**：
- 严肃主题
- 社会批判
- 冷静叙事

**使用强度建议**：标准

---

### 【风格2：峭拔】

**定义**：
简洁有力，像刀削斧砍，不拖泥带水。

**核心特征**：
- 删除所有废话
- 用短句，有力度
- 直奔主题，不铺垫
- 像电报，惜字如金

**适用场景**：
- 观点输出
- 需要力量感的文章
- 时间有限的表达

**使用强度建议**：强化

---

### 【风格3：疏淡】

**定义**：
平淡自然，不刻意营造，像清水一样透明。

**核心特征**：
- 避免华丽词汇
- 用日常语言
- 不追求金句和亮点
- 像白开水，但耐读

**适用场景**：
- 生活随笔
- 需要自然感的文章
- 长文（避免疲劳）

**使用强度建议**：标准

---

### 【风格4：简洁】

**定义**：
删繁就简，能用一个词不用两个。

**核心特征**：
- 删除所有冗余词汇
- 用短句
- 不重复表达
- 追求信息密度

**适用场景**：
- 所有文体的基础风格
- 信息类文章
- 快速阅读的内容

**使用强度建议**：标准（删除30-50%冗余）

---

### 【风格5：克制】

**定义**：
有情绪但不外露，点到为止，不渲染。

**核心特征**：
- 允许情绪，但不放大
- 用事实传递情绪，不直接说
- 避免感叹号和夸张词
- 像压抑的情绪，更有力量

**适用场景**：
- 深度情感类文章
- 需要共鸣但不煽情的内容

**使用强度建议**：标准

---

### 【风格6：冷静】

**定义**：
理性分析，不带个人情绪，像观察者。

**核心特征**：
- 避免主观判断
- 用数据和事实说话
- 保持客观视角
- 像分析报告

**适用场景**：
- 分析类文章
- 数据驱动的内容
- 需要公信力的文章

**使用强度建议**：标准

---

### 【风格7：疏离】

**定义**：
与读者保持距离，不追求亲近感，像陌生人叙述。

**核心特征**：
- 避免"你""我们"等拉近距离的词
- 用第三人称
- 不解释，不讨好读者
- 像局外人视角

**适用场景**：
- 严肃主题
- 需要客观性的文章
- 不需要互动的内容

**使用强度建议**：标准

## 五、跨文化技法（3种）

### 【技法1：弹幕式】

**定义**：
模仿弹幕评论的即时性和网络化表达。

**核心特征**：
- 用短句，口语化
- 允许网络用语和梗
- 像弹幕一样即时反应
- 碎片化表达

**约束机制**：
```
✓ 允许：卧槽！这也太真实了吧。笑死。
✗ 禁止：看到这里我深感震惊，忍不住笑了出来。
```

**适用场景**：
- 网络文章
- 年轻化内容
- 轻松吐槽类
- 小红书、B站等平台

**不适用场景**：
- 正式场合
- 需要严肃性的内容

**使用强度建议**：标准（保留网感但不过度）

**提示词要素**：
```
- 用弹幕式的即时反应
- 短句，口语化，网络用语
- 像在评论区发弹幕
- 允许"卧槽""笑死"等表达
```

---

### 【技法2：第二人称】

**定义**：
用"你"来写，强化代入感和对话感。

**核心特征**：
- 全文用"你"
- 像对着读者说话
- 增强参与感
- 拉近距离

**适用场景**：
- 所有需要亲近感的内容
- 教程类文章
- 情感类文章

**使用强度建议**：完整使用

**提示词要素**：
```
- 全文用第二人称"你"
- 像对着读者说话
- 增强代入感
```

---

### 【技法3：意识流】

**定义**：
模仿人的思维流动，跳跃、重复、不连贯。

**核心特征**：
- 允许跳跃和重复
- 不追求逻辑连贯
- 像内心独白
- 保留思维的真实状态

**约束机制**：
```
✓ 允许：雨。又下雨了。为什么总是下雨。小时候也下雨。那天也下雨。
✗ 禁止：雨天总是让我想起童年的某个下雨天...（太文学化）
```

**适用场景**：
- 内心独白类文章
- 情绪类文章
- 文学创作

**不适用场景**：
- 逻辑类文章
- 信息传达类内容

**使用强度建议**：标准

## 六、组合策略

### 高协同组合（效果显著）

以下组合配合使用，效果显著好于单独使用：

1. **白描 + 特稿风格**
   - 适合：深度报道、纪实类写作
   - 效果：真实感强，有现场感
   - 理由：白描提供客观基础，特稿提供结构

2. **杂文 + 书信体**
   - 适合：公众号观点输出
   - 效果：有态度又有亲近感
   - 理由：杂文提供立场，书信体提供对话感

3. **速写 + 流水账 + 第二人称**
   - 适合：小红书种草笔记
   - 效果：真实、随意、有代入感
   - 理由：三者叠加营造"真人分享"感

4. **杂文 + 弹幕式**
   - 适合：网络观点文章
   - 效果：有观点又接地气
   - 理由：杂文提供立场，弹幕式提供网感

5. **意识流 + 第二人称**
   - 适合：情绪类文章
   - 效果：强代入感，情绪感染力强
   - 理由：意识流提供情绪流动，第二人称提供代入感

### 中等协同组合

以下组合有提升，但不如高协同组合明显：

1. **白描 + 杂文**
   - 适合：批判性报道
   - 效果：客观但有态度

2. **随笔 + 书信体**
   - 适合：生活感悟类
   - 效果：轻松亲切

3. **速写 + 弹幕式**
   - 适合：轻松吐槽
   - 效果：快速有趣

### 负向组合（避免使用）

以下组合会互相冲突，降低效果：

1. **白描 + 散文诗**
   - 冲突：白描要求简洁，散文诗要求意境
   - 结果：风格撕裂

2. **杂文 + 冷静风格**
   - 冲突：杂文要求有态度，冷静要求客观
   - 结果：立场模糊

3. **流水账 + 峭拔风格**
   - 冲突：流水账要求详细，峭拔要求精简
   - 结果：风格矛盾

4. **意识流 + 逻辑严密**
   - 冲突：本质上相反
   - 结果：无法共存

## 七、使用建议

### 单一技法使用

- 初学者：从单一技法开始，掌握一个再学下一个
- 推荐入门：白描、杂文、书信体（最实用）

### 双技法组合

- 进阶用户：选择高协同组合
- 注意强度搭配：一个标准，一个强化

### 三技法及以上

- 高级用户：场景深度定制
- 建议有主次：1个主力 + 1-2个辅助
- 避免技法过多导致风格混乱

### 强度控制

- 轻度：保持可读性，去AI味效果较弱
- 标准：平衡去AI味与可读性（推荐）
- 强化：极致去AI味，可能影响可读性
