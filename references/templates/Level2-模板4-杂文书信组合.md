# Level 2 进阶模板：杂文书信组合

## 适用场景

- 公众号观点文章
- 情感类评论
- 需要对话感的批判性文章
- 价值观输出

## 技法配置

- **核心技法**：杂文（标准使用）
- **辅助技法**：书信体（完整使用）

## 完整提示词

```
写一篇关于 [主题] 的文章。

【必须同时使用以下两种技法】

【技法1：杂文】
- 必须有明确的立场和态度，不打太极
- 允许直接表达情绪（愤怒、讽刺、焦虑）
- 不要追求"客观中立"，要敢于批判
- 可以打破逻辑严密性，注入个人经验和直觉
- 允许跳跃性思维，不必面面俱到

【技法2：书信体】
- 全文用第二人称"你"来写，像写给朋友的信
- 可以直接对话："你有没有发现..."
- 允许省略主语，口语化表达
- 可以用"对吗？""是吧？"等反问
- 整体语气是倾诉和交流，不是宣讲

【示例对比】

❌ 错误：从客观角度分析，读者可能会遇到这种情况...
✅ 正确：你有没有遇到过这种情况？说实话，我真受够了。

❌ 错误：我们应该理性看待这个问题...
✅ 正确：你懂我意思吧？别跟我扯什么理性，这事儿就是不对。

【禁止项】

❌ 不要三段论结构（引入-分析-总结）
❌ 不要"综上所述"等套话
❌ 不要堆砌排比句和金句
❌ 不要空洞升华和心灵鸡汤
❌ 不要过度使用形容词
❌ 不要用第三人称"读者""大家"

【检验标准】

如果读完让人感觉：
✓ 像朋友在跟我聊天
✓ 作者有明确的态度
✓ 有真实的情绪和观点
✓ 读起来不像"AI生成"
→ 说明达标
```

## 核心要求

- 杂文：明确立场 + 真实情绪 + 跳跃思维
- 书信体：全文用"你" + 对话感 + 口语化

## 禁止项

- 不要三段论结构
- 不要套话和金句
- 不要空洞升华
- 不要用第三人称

## 检验标准

- 像朋友聊天
- 有明确态度
- 有真实情绪
- 不像AI生成

- **去AI味强度**：极高
- **可读性**：高
