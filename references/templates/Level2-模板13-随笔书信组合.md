# Level 2 进阶模板：随笔书信组合

## 适用场景
- 生活感悟、读书笔记、个人博客

## 技法配置
- **核心技法**：随笔（标准使用）+ 书信体（完整使用）

## 完整提示词
```
写一篇关于 [主题] 的随笔。

【技法组合：随笔 + 书信体】

【随笔】
- 结构松散，想到哪写到哪
- 允许离题，允许闲笔
- 像絮叨，不求简洁
- 保留思考过程的曲折

【书信体】
- 全文用"你"
- 像和朋友聊天
- 可以反问："对吧？""是吧？"
- 倾诉和交流的语气

【示例】
✅ 正确：说到这个，我突然想起另一件事。你有没有遇到过？就是那种...
❌ 错误：首先我们来看第一点，其次...

【禁止项】
❌ 不要严格结构
❌ 不要刻意构思
❌ 不要宣讲式

【检验标准】
✓ 轻松亲切
✓ 像闲聊
✓ 自然流畅
```

## 预期效果
- **去AI味强度**：高
- **适配度**：适合个人表达
