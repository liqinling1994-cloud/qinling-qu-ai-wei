# Level 2 进阶模板：意识流第二人称组合

## 适用场景
- 情绪类文章、内心独白、情感表达

## 技法配置
- **核心技法**：意识流（标准使用）+ 第二人称（完整使用）

## 完整提示词
```
写一篇关于 [主题] 的情绪表达。

【技法组合：意识流 + 第二人称】

【意识流】
- 允许跳跃和重复
- 不追求逻辑连贯
- 像内心独白
- 保留思维的真实状态

【第二人称】
- 全文用"你"
- 增强代入感
- 像对着读者说话

【示例】
✅ 正确：你懂吗。雨。又下雨了。为什么总是下雨。你记得吗。小时候也下雨。那天也下雨。
❌ 错误：雨天总是让我想起童年的某个下雨天...

【禁止项】
❌ 不要逻辑严密
❌ 不要文学化
❌ 不要理性分析

【检验标准】
✓ 情绪感染力强
✓ 强代入感
✓ 真实流动
```

## 预期效果
- **去AI味强度**：很高
- **适配度**：适合情绪类
