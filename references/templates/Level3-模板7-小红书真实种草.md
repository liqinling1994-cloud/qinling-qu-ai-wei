# Level 3 专家模板：小红书真实种草

## 适用场景

- 小红书产品种草笔记
- 真实体验分享
- 好物推荐
- 使用心得

## 技法配置

- **主力技法**：速写（标准使用）+ 流水账（标准使用）
- **辅助技法**：第二人称（完整使用）+ 弹幕式（轻度使用）

## 完整提示词

```
写一篇小红书笔记，分享 [产品/体验]。

【必须同时使用以下技法组合】

【技法1：速写 - 标准使用】
- 允许不完整的句子
- 用短句，断句，省略号
- 捕捉第一印象，不要二次加工
- 像速写本，保留粗糙感

【技法2：流水账 - 标准使用】
- 按时间顺序记录使用过程
- 不做提炼和总结
- 平铺直叙，事无巨细
- 像记账本一样

【技法3：第二人称 - 完整使用】
- 全文用"你"来写
- 像对着闺蜜/朋友说话
- 增强代入感

【技法4：弹幕式 - 轻度使用】
- 可以用"卧槽""笑死""绝了"等网络用语
- 即时反应，不修饰
- 碎片化表达

【写作要求】

1. 开篇：直接进入
   - 不要"今天给大家分享..."
   - 直接说"昨天买的XX到了"
   - 或者直接"你们要的XX来了"

2. 主体：按使用流程记录
   - 第一次打开：第一印象
   - 使用过程：流水账式记录
   - 遇到的问题：真实记录
   - 意外惊喜：即时反应

3. 结尾：不总结
   - 可以说"就这样"
   - 或者"你们自己看"
   - 不要"总的来说值得购买"

【示例片段】

✅ 正确示范：
"昨天到的。

拆开。包装还行。

试了一下。你猜怎么着？

卧槽。是真的好用。

我之前用的那个，对比一下，差太多了。

具体怎么用呢。

早上。洗完脸。拍这个。然后等一分钟。再擦其他的。

用了三天。你看图。

对了。有个小问题。味道。有点重。但能接受。

就这样。你们自己看。"

【禁止项】

❌ 不要"今天给大家分享..."开头
❌ 不要"总的来说""综上所述"
❌ 不要完整的文案式表达
❌ 不要"强烈推荐""值得入手"等营销话术
❌ 不要堆砌形容词
❌ 不要刻意凑字数

【检验标准】

如果读完让人感觉：
✓ 像真人在分享，不是品牌软文
✓ 随意、真实、有瑕疵
✓ 有代入感，想试试
✓ 完全不像AI写的
→ 说明达标
```

## 核心要求

- 速写：碎片化 + 粗糙感
- 流水账：时间线 + 不总结
- 第二人称：用"你" + 闺蜜感
- 弹幕式：网络用语 + 即时反应

## 禁止项

- 不要标准开头
- 不要总结
- 不要文案式
- 不要营销话术
- 不要堆形容词

## 检验标准

- 像真人分享
- 真实有瑕疵
- 有代入感
- 不像AI

## 预期效果

- **去AI味强度**：S级（极高）
- **可读性**：高（符合小红书习惯）
- **适配度**：完美适配小红书
- **转化潜力**：高（真实感强）
