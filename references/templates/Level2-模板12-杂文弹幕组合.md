# Level 2 进阶模板：杂文弹幕组合

## 适用场景
- 网络观点文章、年轻化评论、B站/知乎内容

## 技法配置
- **核心技法**：杂文（标准使用）+ 弹幕式（标准使用）

## 完整提示词
```
写一篇关于 [主题] 的网络评论。

【技法组合：杂文 + 弹幕式】

【杂文】
- 有明确的立场和态度
- 允许直接表达情绪
- 可以跳跃思维
- 不追求客观中立

【弹幕式】
- 用网络用语和梗
- 短句，即时反应
- 像发弹幕一样
- 碎片化表达

【示例】
✅ 正确：说实话，这事儿吧。卧槽。离谱。你懂我意思吧？就是不对。
❌ 错误：从理性角度分析，这个问题确实存在一定的不合理性...

【禁止项】
❌ 不要正经表达
❌ 不要客观中立
❌ 不要书面语

【检验标准】
✓ 有态度有网感
✓ 年轻化表达
✓ 接地气
```

## 预期效果
- **去AI味强度**：很高
- **适配度**：适合网络平台
