# Level 1 基础模板：杂文批评

## 适用场景

- 观点评论
- 批判性文章
- 时事评论
- 社会观察

## 技法配置

- **核心技法**：杂文（标准使用）
- **辅助技法**：无

## 完整提示词

```
写一篇关于 [主题] 的评论文章。

【核心要求：杂文】

必须遵守以下约束：

1. 必须有明确的立场和态度
   - 不要打太极
   - 不要"客观中立"
   - 直接表达你的观点

2. 允许直接表达情绪
   - 可以愤怒、讽刺、焦虑
   - 可以用"说实话""我真的受够了"
   - 不要压抑情绪

3. 允许跳跃性思维
   - 可以突然想起别的事
   - 可以跑题
   - 可以用"说起来...""想到..."
   - 不必面面俱到

4. 可以打破逻辑严密性
   - 不必三段论
   - 可以跳跃
   - 允许不完整的论证

【示例对比】

❌ 错误：从某种角度来看，这种说法可能存在一定的问题...
✅ 正确：说实话，我真的受够了这种"为你好"的说辞。

❌ 错误：我们需要客观分析这个问题的多个方面...
✅ 正确：别跟我扯什么客观，这事儿就是不对。

【禁止项】

❌ 不要追求"客观中立"
❌ 不要三段论结构
❌ 不要"综上所述"等套话
❌ 不要压抑情绪和态度

【检验标准】

如果读完让人感觉：
✓ 作者有明确的态度
✓ 有真实的情绪
✓ 敢于批判
✓ 不是AI生成的
→ 说明达标
```

## 核心要求

- 必须有明确的立场
- 允许直接表达情绪
- 允许跳跃性思维
- 可以打破逻辑严密性

## 禁止项

- 不要追求"客观中立"
- 不要三段论结构
- 不要"综上所述"等套话
- 不要压抑情绪和态度

## 检验标准

- 作者有明确的态度
- 有真实的情绪
- 敢于批判
- 不是AI生成的

## 预期效果

- **去AI味强度**：很高
- **可读性**：高
- **适配度**：适合观点类文章
