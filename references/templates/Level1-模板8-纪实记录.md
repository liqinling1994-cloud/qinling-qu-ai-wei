# Level 1 基础模板：纪实记录

## 适用场景
- 现场报道、事件记录、调查报告

## 技法配置
- **核心技法**：白描（标准使用）+ 写生（标准使用）

## 完整提示词
```
写一篇关于 [主题] 的纪实记录。

【技法：白描 + 写生】
- 只写看到的，不加评价
- 完全基于观察，不加想象
- 用"我看到..."的视角
- 删除所有形容词和副词
- 像摄像机一样记录

【禁止项】
❌ 不要主观评价
❌ 不要推测动机
❌ 不要文学化表达

【检验标准】
✓ 像纪录片
✓ 强调在场感
✓ 客观真实
```

## 预期效果
- **去AI味强度**：高
- **适配度**：适合纪实类
