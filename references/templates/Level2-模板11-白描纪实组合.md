# Level 2 进阶模板：白描纪实组合

## 适用场景
- 深度报道、调查类文章、特稿

## 技法配置
- **核心技法**：白描（标准使用）+ 特写（强化使用）

## 完整提示词
```
写一篇关于 [主题] 的深度报道。

【技法组合：白描 + 特写】

【白描】
- 删除所有形容词和副词
- 只用名词+动词
- 不加评价，只描述

【特写】
- 关键时刻：聚焦一个细节
- 放大呈现，其他虚化
- 用具体的感官描写

【示例】
✅ 正确：他的手指在键盘上停了三秒。第一秒，悬着。第二秒，抖了一下。第三秒，按下。
❌ 错误：他思考良久后终于做出了决定...

【禁止项】
❌ 不要形容词堆砌
❌ 不要宏大叙事
❌ 不要空泛概括

【检验标准】
✓ 真实感强
✓ 有现场感
✓ 细节有力
```

## 预期效果
- **去AI味强度**：很高
- **适配度**：适合深度报道
