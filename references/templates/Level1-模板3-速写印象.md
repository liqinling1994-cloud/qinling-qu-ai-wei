# Level 1 基础模板：速写印象

## 适用场景

- 现场记录
- 旅行见闻
- 快速印象记
- 碎片化表达

## 技法配置

- **核心技法**：速写（标准使用）
- **辅助技法**：无

## 完整提示词

```
写一篇关于 [主题] 的快速记录。

【核心要求：速写】

必须遵守以下约束：

1. 允许不完整的句子
   - 可以只有名词
   - 可以省略主语
   - 可以断句

2. 捕捉第一印象
   - 不要二次加工
   - 不要修改润色
   - 保留粗糙感

3. 像速写本一样
   - 快速记录
   - 不求完整
   - 印象式

4. 用短句、断句、省略号
   - 像现场笔记
   - 碎片化
   - 即时性

【示例对比】

❌ 错误：天空突然下起了雨，我这才想起忘记带伞，瞬间被淋得湿透
✅ 正确：下雨了。伞。忘带了。湿透。

❌ 错误：咖啡馆里人很多，大家都在各自做着自己的事情
✅ 正确：咖啡馆。人多。有人看书。有人敲键盘。

【禁止项】

❌ 不要追求完整的句子
❌ 不要二次加工润色
❌ 不要连贯的叙述
❌ 不要文学化表达

【检验标准】

如果读完让人感觉：
✓ 像速写本
✓ 粗糙、即时
✓ 第一印象
✓ 有现场感
→ 说明达标
```
