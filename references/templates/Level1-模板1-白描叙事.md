# Level 1 基础模板：白描叙事

## 适用场景

- 纪实类写作
- 新闻报道
- 调查报告
- 需要客观冷静的叙述

## 技法配置

- **核心技法**：白描（标准使用）
- **辅助技法**：无

## 完整提示词

```
写一篇关于 [主题] 的文章。

【核心要求：白描】

必须遵守以下约束：

1. 删除所有形容词和副词
   - 不要用"非常""极其""十分"等程度副词
   - 不要用"美丽的""愤怒的""悲伤的"等形容词
   - 只用名词+动词

2. 只写看到的，不加评价
   - 只描述事实和动作
   - 不要解释为什么
   - 不要评价好坏

3. 像摄像机一样记录
   - 客观呈现
   - 不加工
   - 不渲染

【示例对比】

❌ 错误：他非常愤怒，脸色变得极其难看，狠狠地摔门而去
✅ 正确：他握紧拳头，转身，摔门，走了

❌ 错误：天空突然下起了瓢泼大雨，路人纷纷加快脚步寻找躲雨的地方
✅ 正确：雨下了。人跑起来。有人躲进商店。

【禁止项】

❌ 不要用形容词和副词
❌ 不要做主观评价
❌不要解释动机
❌ 不要渲染情绪

【检验标准】

如果读完让人感觉：
✓ 像看纪录片
✓ 客观、冷静
✓ 只有事实，没有评论
→ 说明达标
```

## 核心要求

- 删除80%以上的形容词和副词
- 只用名词+动词结构
- 不做任何主观评价
- 像摄像机一样记录

## 禁止项

- 不要用形容词和副词
- 不要做主观评价
- 不要解释动机
- 不要渲染情绪

## 检验标准

- 像看纪录片
- 客观、冷静
- 只有事实，没有评论

## 预期效果

- **去AI味强度**：高
- **可读性**：高
- **适配度**：适合纪实类写作
