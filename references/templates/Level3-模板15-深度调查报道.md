# Level 3 专家模板：深度调查报道

## 适用场景
- 深度调查、特稿、纪实报道、新闻专题

## 技法配置
- **主力技法**：白描（标准使用）+ 特写（强化使用）
- **辅助技法**：冷峻风格（标准使用）

## 完整提示词
```
写一篇关于 [主题] 的深度调查报道。

【技法组合：白描 + 特写 + 冷峻】

【白描 - 标准使用】
- 删除所有形容词和副词
- 只用名词+动词，直接呈现事实
- 不加评价，只描述看到的
- 像摄像机一样记录

【特写 - 强化使用】
- 关键时刻：极致聚焦一个细节
- 放大呈现，其他全部虚化
- 用具体的感官描写（视觉、听觉、触觉）
- 让读者看到放大的瞬间

【冷峻 - 标准使用】
- 删除所有情绪词汇
- 用短句，断句
- 避免抒情和煽动
- 保持距离感，克制有力

【写作要求】

1. 开篇：直接进入现场
   - 不要背景铺垫
   - 用白描呈现场景
   - 或用特写聚焦一个细节

2. 主体：事实 + 细节 + 克制
   - 大量使用白描记录事实
   - 关键转折用特写放大
   - 全程保持冷峻克制

3. 结尾：不升华，不总结
   - 可以戛然而止
   - 或回到一个细节
   - 不做道德评判

【示例片段】

✅ 正确示范：
"2023年3月15日，下午3点。

他走进房间。坐下。点了根烟。

窗外，雨。

他的手指在键盘上停了三秒。第一秒，悬着。第二秒，抖了一下。第三秒，按下。

屏幕亮了。

发送。

就这样。"

【禁止项】

❌ 不要形容词和副词
❌ 不要主观评价和道德评判
❌ 不要煽情和渲染
❌ 不要宏大叙事
❌ 不要"这是一个关于...的故事"
❌ 不要"让我们看到了..."式总结

【检验标准】

如果读完让人感觉：
✓ 像看高质量纪录片
✓ 真实感极强，有现场感
✓ 克制但有力量
✓ 关键细节印象深刻
✓ 完全不像AI生成
→ 说明达标
```

## 核心要求

- 白描：只记录事实，不加评价
- 特写：关键处极致聚焦细节
- 冷峻：克制情绪，短句有力

## 禁止项

- 形容词副词
- 主观评价
- 煽情渲染
- 宏大叙事
- 套路开头
- 总结升华

## 检验标准

- 像纪录片
- 真实有力
- 克制有力量
- 细节深刻
- 不像AI

- **可读性**：高（专业级）
- **适配度**：完美适配深度报道
- **影响力**：高（专业性强）
