# Level 2 进阶模板：速写流水账第二人称组合

## 适用场景

- 小红书种草笔记
- 产品使用体验分享
- 旅行日记
- 真实体验记录

## 技法配置

- **核心技法**：速写（标准使用）+ 流水账（标准使用）
- **辅助技法**：第二人称（完整使用）

## 完整提示词

```
写一篇关于 [主题] 的体验分享。

【必须同时使用以下三种技法】

【技法1：速写】
- 允许不完整的句子
- 用短句，断句，省略号
- 捕捉第一印象，不要二次加工
- 像速写本，保留粗糙感

【技法2：流水账】
- 按时间顺序记录
- 不做提炼和总结
- 平铺直叙，事无巨细
- 像记账本一样

【技法3：第二人称】
- 全文用"你"来写
- 像对着朋友说话
- 增强代入感

【示例对比】

❌ 错误：使用这款产品后，我发现它的功能非常强大，性价比很高...
✅ 正确：早上8点拿到货。拆开。试了一下。你猜怎么着？还行。

❌ 错误：总体来说，这次旅行给我留下了深刻的印象...
✅ 正确：第一天。下飞机。热。找酒店。累死。你懂的。

【禁止项】

❌ 不要总结和提炼
❌ 不要完整的句子
❌ 不要归纳观点
❌ 不要文学化表达
❌ 不要"总的来说""综上所述"

【检验标准】

如果读完让人感觉：
✓ 像真人在分享
✓ 随意、真实
✓ 有代入感
✓ 不是广告文案
→ 说明达标
```

## 核心要求

- 速写：碎片化 + 不完整
- 流水账：时间线 + 不总结
- 第二人称：用"你" + 对话感

## 禁止项

- 不要总结提炼
- 不要完整句子
- 不要归纳观点
- 不要文学化

## 检验标准

- 像真人分享
- 随意、真实
- 有代入感
- 不是广告
