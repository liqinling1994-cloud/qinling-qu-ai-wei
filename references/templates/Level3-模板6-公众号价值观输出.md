# Level 3 专家模板：公众号价值观输出

## 适用场景

- 公众号深度观点文章
- 价值观输出
- 社会话题评论
- 需要态度 + 共鸣的内容

## 技法配置

- **主力技法**：杂文（标准使用）+ 书信体（完整使用）
- **辅助技法**：冷峻风格（轻度使用）

## 完整提示词

```
写一篇公众号文章，主题是 [用户主题]。

【必须同时使用以下技法组合】

【技法1：杂文 - 标准使用】
- 必须有明确的立场和态度，不打太极
- 允许直接表达情绪（愤怒、讽刺、焦虑）
- 不要追求"客观中立"，要敢于批判
- 可以打破逻辑严密性，注入个人经验和直觉
- 允许跳跃性思维，不必面面俱到

【技法2：书信体 - 完整使用】
- 全文用第二人称"你"来写，像写给朋友的信
- 可以直接对话："你有没有发现..."、"你懂我意思吧？"
- 允许省略主语，口语化表达
- 可以用"对吗？""是吧？""对不对？"等反问
- 整体语气是倾诉和交流，不是宣讲

【技法3：冷峻风格 - 轻度使用】
- 关键时刻用短句
- 不煽情，但有力量
- 克制情绪的外露，但让人感受到压抑的力量

【写作要求】

1. 开篇：直接切入，不要铺垫
   - 用"你"开头
   - 直接抛出观点或场景
   - 不要"在当下这个时代..."

2. 主体：态度 + 对话 + 真实
   - 有明确的立场
   - 像跟朋友聊天
   - 可以跑题，可以跳跃
   - 允许不完美

3. 结尾：不升华，不总结
   - 可以戛然而止
   - 可以留一个问题
   - 不要"让我们一起..."

【示例片段】

✅ 正确示范：
"你有没有遇到过这种情况？

别人跟你说"我这是为你好"。然后你就得感恩戴德。

说实话，我真的受够了。

为我好？你确定？还是为你自己方便？

你懂我意思吧。很多时候，所谓的"为你好"，不过是一种道德绑架。对不对？"

【禁止项】

❌ 不要三段论结构（引入-分析-总结）
❌ 不要"综上所述""总而言之"等套话
❌ 不要堆砌排比句和金句
❌ 不要空洞升华和心灵鸡汤
❌ 不要过度使用形容词
❌ 不要用"读者""大家""我们"等第三人称或第一人称复数
❌ 不要对称式小标题

【检验标准】

如果读完让人感觉：
✓ 像朋友在跟我聊天，不是在对我宣讲
✓ 作者有明确的态度，不是骑墙派
✓ 有真实的情绪和观点，不是假大空
✓ 读起来完全不像"AI生成"
✓ 想转发、想讨论
→ 说明达标
```

## 核心要求

- 杂文：立场鲜明 + 敢于批判 + 真实情绪
- 书信体：全文用"你" + 强对话感
- 冷峻：关键处短句 + 克制有力

## 禁止项

- 三段论结构
- 套话金句
- 空洞升华
- 第三人称
- 对称小标题

## 检验标准

- 像朋友聊天
- 立场鲜明
- 真实情绪
- 不像AI
- 想转发
