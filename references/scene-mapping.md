## 场景→技法推荐矩阵


### 【场景1：公众号爆款】

**核心需求**：观点 + 传播 + 对话感

**推荐技法组合**：

**方案1（推荐）**：杂文（标准）+ 书信体（完整）
- **推荐理由**：杂文提供明确立场和批判性，书信体增强对话感和亲近感，高协同组合
- **使用强度**：标准（适合大众传播）
- **适配度**：很高
- **参考模板**：Level3-模板6（公众号价值观输出）

**方案2（备选）**：杂文（标准）+ 弹幕式（轻度）
- **推荐理由**：杂文提供立场，弹幕式增加网感
- **适配度**：高

## 使用说明

### 如何使用本映射表

1. **识别场景**：根据用户需求和关键词，匹配场景类型
2. **选择方案**：优先推荐方案1，方案2作为备选
3. **调整强度**：根据具体需求微调技法使用强度
4. **应用模板**：如果有对应模板，直接使用

### 强度调整原则

- **轻度**：保持可读性，去AI味效果较弱，适合正式场合
- **标准**：平衡去AI味与可读性，适合大众传播（推荐）
- **强化**：极致去AI味，可能影响可读性，适合个性化场景

## 特殊场景处理

### 混合场景

有时一个任务可能涉及多个场景：

**识别规则**：
```
如果同时包含多个场景关键词：
1. 找出最主要的场景（关键词最多的）
2. 从主场景推荐
3. 可以融合次要场景的特征
```

**示例**：

```
输入："写一段关于菜市场的批评性观察"

分析：
- 主场景：日常生活（菜市场）
- 次场景：社会批评（批评性）

推荐：汪曾祺式 + 带点批判
或：白描 + 杂文风格
```

---

### 用户明确指定风格

如果用户已经说了具体风格：

```
用户："用鲁迅式写..."

处理：
- 不再推荐，直接使用用户指定的
- 跳过场景识别和推荐环节
- 直接进入约束应用阶段
```

---

### 不确定场景

如果无法明确识别场景：

```
处理：
1. 询问用户：
   "你希望这篇文章：
   A. 批判性的
   B. 生活化的
   C. 随意记录的
   D. 其他（请描述）"

2. 根据用户选择匹配场景
```
