# 验证规则库

详细的AI味检测标准和评分规则。

---

## 验证流程

```
生成文本 → 12项检查 → 计算得分 → 判定状态 → 输出报告
```

---

## 12项检查清单详解

### 第一类：修饰层面（4项）

#### 检查1：形容词是否减少？

**检测标准**：

```
统计形容词数量占比：
- AI倾向：15-25%
- 人类倾向：5-10%
```

**常见AI形容词**：
- 叠词类：淅淅沥沥、灰蒙蒙、热热闹闹、高高兴兴
- 程度类：非常、极其、十分、格外、特别、相当
- 空洞类：美好的、深刻的、重要的、难忘的、宝贵的

**判定规则**：

| 形容词占比 | 判定 |
|-----------|------|
| < 10% | ✓ 通过 |
| 10-15% | ✓ 勉强通过 |
| > 15% | ✗ 不通过 |

**示例对比**：

```
❌ 不通过：
"这是一个非常美好的、令人难忘的、意义深远的经历。"
（形容词占比：40%）

✓ 通过：
"这个经历我记得很清楚。"
（形容词占比：0%）
```

---

#### 检查2：副词是否减少？

**检测标准**：

```
统计副词数量占比：
- AI倾向：10-20%
- 人类倾向：3-8%
```

**常见AI副词**：
- 程度副词：非常、十分、极其、格外、相当
- 时间副词：渐渐、慢慢、逐渐、终于
- 方式副词：默默地、悄悄地、静静地、轻轻地

**判定规则**：

| 副词占比 | 判定 |
|---------|------|
| < 8% | ✓ 通过 |
| 8-12% | ✓ 勉强通过 |
| > 12% | ✗ 不通过 |

**示例对比**：

```
❌ 不通过：
"他慢慢地、默默地、悄悄地走了。"
（副词堆砌）

✓ 通过：
"他走了。"
（无副词）
```

---

#### 检查3：是否避免了叠词？

**检测标准**：

```
是否出现以下类型的叠词：
- AABB型：淅淅沥沥、高高兴兴、安安静静
- ABB型：灰蒙蒙、慢吞吞、空荡荡
- ABAB型：雪白雪白、火红火红
```

**判定规则**：

| 叠词数量 | 判定 |
|---------|------|
| 0个 | ✓ 通过 |
| 1个 | ✓ 勉强通过（如果是对话） |
| ≥ 2个 | ✗ 不通过 |

**例外情况**：
- 如果是模拟口语对话，1个叠词可以接受
- 如果是儿童视角，可以适度放宽

**示例对比**：

```
❌ 不通过：
"淅淅沥沥的雨水从灰蒙蒙的天空中落下。"
（2个叠词）

✓ 通过：
"雨下了。天灰着。"
（无叠词）
```

---

#### 检查4：是否避免了空洞修饰？

**检测标准**：

检测是否出现以下空洞套话：

**意义类**：
- 意义深远、意义重大、刻骨铭心、难以忘怀
- 宝贵的财富、深刻的启示、重要的意义

**情绪类**：
- 激动万分、感慨万千、心潮澎湃、热泪盈眶
- 百感交集、五味杂陈、感慨良多

**比喻类**：
- 像一本书、像一面镜子、像一座桥梁
- 犹如...一般、宛如...一样

**判定规则**：

| 套话数量 | 判定 |
|---------|------|
| 0个 | ✓ 通过 |
| 1个 | ✓ 勉强通过 |
| ≥ 2个 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过：
"读书是人生中最宝贵的财富，它给我们带来深刻的启示。"
（2个套话）

✓ 通过：
"读了这本书，我想明白了一些事。"
（无套话）
```

---

### 第二类：结构层面（4项）

#### 检查5：是否避免了过度工整？

**检测标准**：

检查结构模式：

**工整模式（AI倾向）**：
- 每段长度相近（±20字以内）
- 每段都是3-4句
- 段落开头有明显的序列词（首先、其次、再次）

**自然模式（人类倾向）**：
- 段落长短不一
- 句子数量不固定
- 没有明显的序列模板

**判定规则**：

| 模式 | 判定 |
|------|------|
| 段落长度差异 > 50% | ✓ 通过 |
| 段落长度差异 30-50% | ✓ 勉强通过 |
| 段落长度差异 < 30% | ✗ 不通过 |

**示例对比**：

```
❌ 不通过（工整模式）：
第一段：50字，3句
第二段：48字，3句
第三段：52字，3句
（高度一致）

✓ 通过（自然模式）：
第一段：30字，2句
第二段：80字，5句
第三段：15字，1句
（长短不一）
```

---

#### 检查6：是否没有明显的"三段论"？

**检测标准**：

检测是否符合"三段论"模板：

**典型三段论模板**：
```
段1：提出问题/现象
段2：分析原因/影响
段3：总结/呼吁
```

或：

```
首先...
其次...
最后...
```

**判定规则**：

| 情况 | 判定 |
|------|------|
| 无明显三段结构 | ✓ 通过 |
| 有三段但不规整 | ✓ 勉强通过 |
| 明显三段论 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过：
"首先，读书的重要性体现在...
其次，读书能够帮助我们...
最后，我们应该..."
（明显三段论）

✓ 通过：
"读书这事儿，说起来就想笑。
小时候被逼着读，讨厌得很。
后来没人管了，反倒自己找书看。
昨天翻到..."
（无规整结构）
```

---

#### 检查7：是否有跳跃或省略？

**检测标准**：

检测是否有以下特征：

**跳跃标志**：
- 突然转换话题
- "说起来..."、"想到..."、"对了..."
- 思维跳跃，不完整的逻辑链

**省略标志**：
- 句子不完整
- 省略主语、宾语
- 留白、不解释

**判定规则**：

| 跳跃/省略次数 | 判定 |
|-------------|------|
| ≥ 2次 | ✓ 通过 |
| 1次 | ✓ 勉强通过 |
| 0次 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过（无跳跃）：
"我去了书店。书店里有很多书。我挑了一本。然后我买了。"
（完整逻辑链）

✓ 通过（有跳跃）：
"去了书店。满架子的书，不知道该买哪本。
说起来，上次买的那本还没看完呢。"
（有跳跃和省略）
```

---

#### 检查8：是否段落长短不一？

**检测标准**：

计算段落长度的变异系数（CV）：

```
CV = 标准差 / 平均值

- AI倾向：CV < 0.3（长度一致）
- 人类倾向：CV > 0.5（长短不一）
```

**判定规则**：

| CV值 | 判定 |
|------|------|
| > 0.5 | ✓ 通过 |
| 0.3-0.5 | ✓ 勉强通过 |
| < 0.3 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过：
段1：100字
段2：105字
段3：98字
段4：102字
（CV = 0.03，高度一致）

✓ 通过：
段1：30字
段2：150字
段3：10字
段4：80字
（CV = 0.65，长短不一）
```

### 第三类：表达层面（4项）

#### 检查9：是否更口语化？

**检测标准**：

检测口语化特征：

**口语化标志**：
- 简短句子（< 20字）
- 日常词汇（不是书面语）
- 语气词（吧、呢、啊、嘛）
- 不完整句子

**书面语标志**：
- 长句（> 30字）
- 正式词汇（进行、实施、开展）
- 无语气词
- 完整规范的句子

**判定规则**：

| 口语化特征数量 | 判定 |
|--------------|------|
| ≥ 3个 | ✓ 通过 |
| 1-2个 | ✓ 勉强通过 |
| 0个 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过（书面语）：
"我们应当认真思考这个问题，并采取有效措施进行解决。"
（正式、完整）

✓ 通过（口语化）：
"这事儿得好好想想。怎么办呢？"
（口语、简短、有语气词）
```

---

#### 检查10：是否有个人视角？

**检测标准**：

检测个人化特征：

**个人化标志**：
- 第一人称（我、我们）
- 个人经历（我见过、我觉得）
- 个人偏见（我就是不喜欢）
- 主观判断（不客观的评价）

**客观化标志**：
- 第三人称（人们、大家）
- 客观陈述（据统计、研究表明）
- 没有个人色彩
- 试图全面客观

**判定规则**：

| 个人化特征 | 判定 |
|----------|------|
| ≥ 2个 | ✓ 通过 |
| 1个 | ✓ 勉强通过 |
| 0个 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过（客观化）：
"手机依赖现象在当今社会普遍存在。研究表明..."
（第三人称、客观陈述）

✓ 通过（个人化）：
"说到手机，我想起一件事。上周在餐厅，我看见..."
（第一人称、个人经历）
```

---

#### 检查11：是否没有刻意煽情？

**检测标准**：

检测煽情标志：

**煽情标志**：
- 泪水、眼眶湿润、热泪盈眶
- 心中涌起、激动万分、感慨万千
- 刻骨铭心、难以忘怀、永生难忘
- 情绪堆砌的段落

**克制标志**：
- 不直接写情绪
- 只写行为
- 冷静叙述
- 留白

**判定规则**：

| 煽情标志数量 | 判定 |
|------------|------|
| 0个 | ✓ 通过 |
| 1个 | ✓ 勉强通过（如果确实需要） |
| ≥ 2个 | ✗ 不通过 |

**示例对比**：

```
❌ 不通过（煽情）：
"泪水模糊了视线，心中涌起万般不舍，这段刻骨铭心的经历..."
（3个煽情标志）

✓ 通过（克制）：
"火车启动了。他站在原地，没有挥手。"
（无煽情，留白）
```

---

#### 检查12：是否有"说人话"的感觉？

**检测标准**：

综合判断，是否符合：

**"说人话"特征**：
- 像日常聊天
- 不装腔作势
- 不故作深沉
- 简单直接

**"不说人话"特征**：
- 文绉绉
- 故作高深
- 套话连篇
- 刻意升华

**判定规则**：

主观判断：读起来是否像人在说话？

| 感觉 | 判定 |
|------|------|
| 像人说话 | ✓ 通过 |
| 不太确定 | ✓ 勉强通过 |
| 明显不像 | ✗ 不通过 |

**测试方法**：

```
把文本读出声：
- 如果读起来很自然 → 通过
- 如果读起来很别扭 → 不通过
```

## 评分规则

### 计算方法

```
总分 = 通过项数量 / 12

例如：通过9项 → 9/12 = 0.75 = 75分
```

### 评级标准

| 通过项 | 得分 | 评级 | 状态 |
|-------|------|------|------|
| 10-12 | 83-100 | ⭐⭐⭐⭐⭐ | 通过 |
| 7-9 | 58-75 | ⭐⭐⭐⭐ | 通过 |
| 4-6 | 33-50 | ⭐⭐⭐ | 建议优化 |
| 0-3 | 0-25 | ⭐⭐ | 需要重新生成 |

## 优化策略库

根据验证结果，自动匹配优化策略：

**症状**：检查1-4不通过

```
加强技法约束：
- 当前：白描

```
